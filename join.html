🚀 बॉट जॉइन करने की पूरी प्रक्रिया

स्टेप 1: बाइनेंस (Binance) में API सेट करने का पूरा तरीका

*****API Management में जाकर एक नई API Key बनाएँ। Enable Reading और Enable Spot Trading वाले बॉक्स पर टिक लगाएँ। सुरक्षा के लिए: 'Enable Withdrawals' को हमेशा अनटिक (बंद) रखें ताकि आपके पैसे सुरक्षित रहें। IP Restriction: 'Restrict Access to Trusted IPs' को चुनें और यह IP कॉपी करके पेस्ट करें: 2001:16a4:9:bc62:f23b:a3e:e54c:94a9*****

👉 1. बाइनेंस ऐप खोलें: सबसे पहले अपने मोबाइल में Binance App को ओपन करें। सबसे नीचे बाएं तरफ home लिखा होगा उस पर क्लिक करें

👉 2. फिर बाएं तरफ ऊपर तीन लाइन पर क्लिक करें, फिर नीचे स्क्रॉल करके देखिए more service लिखा होगा उस पर क्लिक करें या 'More' पर जाएँ: होम स्क्रीन पर ही आपको दाईं तरफ 'More' (चार छोटे डॉट्स वाला आइकन) दिखेगा, उस पर क्लिक करें。

👉 3. API ढूँढें: नीचे की तरफ स्क्रॉल करें (या सर्च बार में लिखें) और 'API Management' वाले विकल्प को चुनें।

👉 4. नई API बनाएँ: यहाँ 'Create API' बटन पर क्लिक करें। नाम लिखें (अपना जो नाम रखना हो जैसे आपका नाम Bot)। अपनी पहचान (जैसे ईमेल या फ़ोन कोड) वेरिफाई करने के बाद आपको API Key और Secret Key मिल जाएगी।

खास निर्देश: "API Key और Secret Key को तुरंत कॉपी करके कहीं सुरक्षित रख लें, (edit पर save करने से पहले) क्योंकि Secret Key सिर्फ एक ही बार दिखती है। उसके बाद वह छिप जाएगी।" इसी को आप ज्वाइन करते समय दोनों सही से डालना पड़ेगा।

👉 5. सेटिंग्स बदलें (Edit): बनी हुई API के नीचे 'Edit' बटन पर क्लिक करें ताकि आप परमिशन सेट कर सकें।

👉 6. जरूरी परमिशन टिक करें:
- Enable Reading: इसे टिक रहने दें (यह पहले से टिक होता है)।
- Enable Spot & Margin Trading: इस बॉक्स पर टिक लगाएँ।
⚠️ सावधानी: 'Enable Withdrawals' वाले बॉक्स को खाली (Uncheck) छोड़ दें। इसे कभी टिक न करें!

👉 7. IP सुरक्षा सेट करें (सबसे जरूरी): सबसे नीचे 'Restrict access to trusted IPs only' को चुनें। दिए गए बॉक्स में यह IP एड्रेस कॉपी करके पेस्ट करें: 2001:16a4:9:bc62:f23b:a3e:e54c:94a9। (यह trusted IP हमारे मेन पेज पर लिखी है उसे कॉपी करें और इस बॉक्स मे डाल दें. इसके बिना बॉट काम नहीं करेगा) पेस्ट करने के बाद 'Confirm' बटन दबाएँ।

👉 8. सेव करें: अब ऊपर जाकर 'Save' बटन दबाएँ। आपसे बाइनेंस का ऑथेंटिकेटर कोड मांगा जाएगा।

ऑथेंटिकेटर गाइड: (authenticator लोड करके बना लीजियेगा इसके लिए आपको एक बार कोड दिखेगा और उसके निचे एक api key दिखेगा इस key को कॉपी कर लीजियेगा authenticator खोलियेगा उसमें + के निशान पर क्लिक कीजिए Enter a setup key पर क्लिक करना है code name मे जो Binance में नाम डाला है बॉट का इसमें वही नाम डाल दीजिये. Your key में आपने जो अभी बार code के नीचे वाला api key कॉपी किया है उसको इसमें डाल दीजिये बस add पर क्लिक कर दीजिये. अब आपको authenticatar में 6 नंबर दिखने लगेगा उस नंबर कोई कॉपी करके सिक्योरिटी वेरीफाई करना पड़ेगा। और e mail वेरीफिकेशन भी करना पड़ेगा उसमें भी आप जब वेरीफाई करेंगे तो e mail पर 6 नम्बर का कोड जायेगा उसको डालकर वेरीफाई कर लीजिएगा डबल सिक्योरिटी हो जाएगी। इससे कोई भी आपका Binance से कुछ भी चुरा नहीं पायेगा ना कोई हैक कर पायेगा) । उसे भरते ही आपकी API सुरक्षित तरीके से तैयार हो जाएगी।
